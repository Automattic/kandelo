Python Notes API on Kandelo

This page is served by nginx. The /api/ routes below are reverse-proxied to a standard-library Python wsgiref app backed by SQLite — all running in WebAssembly.

  • GET /api/health — liveness
  • GET /api/notes — list notes
  • POST /api/notes — create {title, body}
  • GET|PUT|DELETE /api/notes/{id}
