# Trusted desktop preview image

This canonical product contains the normal rootfs plus Cage/Foot, Sway and
Sway with SFWBar. Programs and bulk runtime data remain lazy references to
normal package outputs. The same shell composer performs its ownership,
layout, eager-size, executable-original and SDK artifact checks. The image
activates the declared compatible program closure; it does not rewrite
research sources or request a host memory capability through demo metadata.

The normal browser gallery binds this authored product to a temporary,
trusted shared-memory machine. The ordinary shell and PHP products keep
ordinary execution and storage. Preview files disappear when the machine
closes. Persistent writable shared files and object resizing are unsupported.

`package.toml` declares the rootfs base packages and selected desktop inputs.
The recipe only composes bytes and runs no SDK compiler, so its toolchain is
`none`. Package and normal gallery/menu/game validation are still required;
source registration is not a working-desktop claim.

After the normal product build, run the actual app/game consumer matrix with:

```sh
cd apps/browser-demos
npx playwright test --config playwright.canonical-shared-desktop.config.ts
```

The tests select this authored product through the normal gallery, with no
production trusted-preview environment flag. They exercise physical Foot
input, Freeciv gameplay/quit, static ScummVM gameplay/quit and Sway startup.
The ordinary Cage, Sway and SFWBar suites retain deeper UI/lifecycle checks.
Missing supported artifacts fail rather than skip. These are commands to run,
not claims that the current canonical build has passed them.
