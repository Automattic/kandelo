# Ruby

CRuby built for Kandelo through the SDK (`build-ruby.sh`), with its standard
library and gems in the `ruby-runtime` archive.

## Memory protection

Kandelo has no page protection (`docs/posix-status.md`, "No page
protection"), and two parts of CRuby rely on it.

**Fiber stacks.** Ruby's fiber pool (`cont.c`) makes the lowest page of every
fiber stack `PROT_NONE` as a guard, and fails the fiber if `mprotect`
refuses. The package declares the `mprotect` fiction (`package.toml`,
`[[fictions]]`) so that this request succeeds without effect, limited to one
64 KiB page per request. A fiber that overflows its stack is not stopped by
the guard: it overwrites the memory below instead of raising. The kernel logs
the first such request of each Ruby process to `/dev/kmsg`, and `ruby.wasm`
records the declaration in its `kandelo.fictions` section.

**Fibers do not run yet.** Kandelo's coroutine backend (`coroutine/kandelo`,
generated by `build-ruby.sh`) has no context switch, so the first
`Fiber#resume` raises `Errno::ENOSYS` ("coroutine_transfer"), after the stack
and its guard are allocated. `Enumerator#next` and anything else built on
fibers fails the same way. The fiction is declared for the fiber pool's guard
so that, once the backend can switch, fibers need no further change; without
it, `Fiber#resume` would fail one step earlier, on the guard, with `ENOTSUP`.

**GC compaction is compiled out** (`-DGC_CAN_COMPILE_COMPACTION=0`).
Compaction's read barrier makes moved heap pages `PROT_NONE` and fixes
references when a read faults. Without protection nothing would fault and
the heap would be corrupted, so it cannot run on Kandelo; it is also what
keeps the fiction to fiber guards, since heap pages and guard pages are both
64 KiB. `GC.compact` and `GC.auto_compact = true` raise
`NotImplementedError`, as on other platforms without compaction, and
`GC::OPTS` does not list `GC_COMPACTION_SUPPORTED`.

Ruby's JIT (YJIT, ZJIT) is disabled; its read/exec requests would stay
`ENOTSUP`.

See "Declared fictions" in `docs/package-management.md`.
