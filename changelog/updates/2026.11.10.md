## 2026.11.10 — Debug, measure and explore your browser computer

Rust development now includes source debugging and coverage reporting,
while searchable manuals and system logs help you explore the computer
and diagnose the software running inside it.

This survey covers changes on `develop` through the source commit below.
They reach stable `main` through the project's tested-promotion process;
landing on `develop` alone is not a full runtime-validation claim.

### Highlights

- **Stop a Rust program at a source line.** Development-checkout commands
  set breakpoints, step over calls and show the stack in a Node or headless
  Chromium guest. Rust local-variable inspection and Firefox/WebKit
  interactive stepping are not implemented.
  [Use the source debugger](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/rust-debugging.md).
- **Measure Rust code coverage inside Kandelo.** The guest SDK includes
  matching profiler support, `llvm-profdata` and `llvm-cov`. Build and run
  an offline Cargo project, merge the profiles, and generate text or HTML
  coverage reports in the same computer.
  [Collect coverage](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/rust-debugging.md#coverage-inside-kandelo).
- **Find help without leaving the terminal.** More packaged tools bring
  their manuals, including the Rust tools, Git, curl, wget, Perl, ffmpeg
  and desktop programs. Use `man` to read installed pages, `whatis` to look
  up a command, and `apropos` or `man -k` to search the manual index.
  [Manuals and search](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/porting-guide.md#the-man-page-index).
- **Ask the computer what went wrong.** `dmesg` exposes the kernel log,
  including missing syscalls a ported program tries to use. Images running
  the new syslog service collect `logger` and application messages in
  `/var/log/messages`.
  [System-log change and its validation scope](https://github.com/Automattic/kandelo/pull/1648).

### Breaking Changes & Migration

- **Rebuild the kernel and host together.** The kernel/host interface is
  now version 6; program ABI remains 56. The `klogctl` interface uses an
  explicit program extension, required only by programs that call it.
  Saved-computer upgrade restrictions still apply.
  [Kernel-log extension](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/program-extensions.md#kernel-log-version-1).

### Agentic Workflows

- **Give an agent more ways to investigate Rust code.** The installed
  Rust SDK can produce coverage reports and source-aware backtraces
  alongside its Cargo build/test workflows. The interactive source debugger
  is a separate development-checkout command using Node or Chromium;
  it does not attach to an existing shared browser computer.
  [Rust development tools](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/rust-debugging.md).

### Ports & Packages

- **Read the manuals for the tools you are using.** Lazy documentation
  archives extend coverage across compiler tools, shells, text utilities,
  network clients and desktop programs. The generated manual index makes
  installed pages searchable. Packages without usable upstream pages use
  the documented alternative sources where available; some Kandelo wrappers
  still have no manual page.
  [Manual sourcing and remaining gaps](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/porting-guide.md#shipping-man-pages).
- **Fetch game launchers when you use them.** DOS and retro-console launcher
  scripts now follow the shell's lazy-loading path, alongside the existing
  on-demand engines and game data. The activities remain discoverable
  before those files are fetched.
  [Lazy game launchers](https://github.com/Automattic/kandelo/pull/1675).

### Correctness

- **Run another Bash command after Ctrl-C.** Fork continuation handling
  fixes a case where interrupting a blocked command left later commands
  hanging. Regression cases cover interrupted sleep and catch-handler
  replay.
  [Shell interruption fix](https://github.com/Automattic/kandelo/pull/1688).
- **Keep saved deletions and directory listings consistent.** Persistent
  compaction preserves image-entry removals when a directory is deleted;
  rootfs directory positions also stay coherent while entries change.
  [Compaction fix](https://github.com/Automattic/kandelo/commit/bd15db6cc3),
  [directory iteration fix](https://github.com/Automattic/kandelo/commit/a4a6e6e6a7).
- **See coherent filesystem information in `df`.** Filesystem reporting
  now describes the mounted filesystems consistently.
  [Filesystem reporting](https://github.com/Automattic/kandelo/pull/1683).
- **Make Cargo notice an installed SDK change.** Compiler-cache and build
  identities include the actual SDK components, so replacing the toolchain
  invalidates stale results. Complete replacement with saved Cargo caches
  is validated on Node; browser replacement still fails during extraction
  with `ENOSPC`. Normal builds and same-SDK cache reuse remain a separate,
  documented workflow.
  [SDK identity and upgrade boundary](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/rust-target.md#cargo-inside-kandelo).

### POSIX Completeness

- **Let programs log through ordinary Unix sockets.** Cross-process
  AF_UNIX datagrams and binding `/dev/log` allow `syslog(3)` messages to
  reach a daemon in another guest process. The kernel log is readable
  independently through `/dev/kmsg`, so readers can follow it concurrently.
  The landed change records focused Node validation; full browser and
  conformance coverage remain follow-up work.
  [Logging support and evidence](https://github.com/Automattic/kandelo/pull/1648).

### New Capabilities

- **Get source context for Rust failures.** Captured backtraces retain
  their own symbol data, even after another capture or a thread exit.
  Node, Chromium and Firefox resolve recorded user source lines; the
  tested WebKit engine supplies names without instruction offsets, so its
  backtraces lack source lines.
  [Rust backtraces](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/rust-target.md#source-diagnostics-and-backtraces).
