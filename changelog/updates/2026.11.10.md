## 2026.11.10 — Debug Rust, check test coverage and find help

New development tools help you follow a Rust program, see which code ran,
and look up commands without leaving the terminal.

These changes have landed on `develop`. They reach stable `main` after the
project's tested-promotion process.

### Highlights

- **Pause a Rust program at the line you want to investigate.** Set a
  breakpoint, step over function calls, and see the calls that led there.
  The debugger runs from a development checkout and starts its own Kandelo
  computer in Node.js or headless Chromium. It cannot inspect Rust variable
  values or attach to an existing browser computer; interactive stepping
  is not available on Firefox or WebKit.
  [Debug a Rust program](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/rust-debugging.md).
- **See which Rust code your tests run.** Generate a coverage report that
  marks the lines executed by a program or its tests. The experimental
  Rust SDK includes the tools to collect results and produce text or HTML
  reports inside Kandelo. Start with the documented offline Cargo workflow.
  [Check code coverage](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/rust-debugging.md#coverage-inside-kandelo).
- **Find the source line behind a Rust failure.** Rust backtraces show the
  sequence of function calls and available source locations, helping you
  trace a failure back to your code. Source lines work on Node.js, Chromium
  and Firefox; the tested WebKit version shows function names only.
  [Read Rust backtraces](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/rust-target.md#source-diagnostics-and-backtraces).
- **Find command help from the terminal.** More tools now ship their
  manuals, including Git, Rust tools and network clients. Read a page with
  `man`, or search for a command by topic with `apropos` or `man -k`.
  Some Kandelo wrapper commands still lack manual pages.
  [Read and search manuals](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/porting-guide.md#the-man-page-index).
- **Look at system logs when a program goes wrong.** Use `dmesg` to read
  kernel messages, including unsupported system calls a program attempts.
  Computers configured with the syslog service also collect application
  messages in `/var/log/messages`. The logging change has focused Node.js
  validation; browser and full conformance checks remain outstanding.
  [System logging and validation](https://github.com/Automattic/kandelo/pull/1648).

### Breaking Changes & Migration

- **Update the kernel and host together.** Their shared interface is now
  version 6; the program ABI remains 56. Programs using the new kernel-log
  interface must declare its extension. Saved-computer upgrade limits
  still apply.
  [Kernel-log compatibility](https://github.com/Automattic/kandelo/blob/39d7a84a53e2dfa4f693e803ff4a08033a743037/docs/program-extensions.md#kernel-log-version-1).

### Fixes

- **Keep using Bash after pressing Ctrl-C.** Interrupting a blocked command
  could leave later commands hanging. You can now cancel the command and
  continue working in the same shell.
  [Shell interruption fix](https://github.com/Automattic/kandelo/pull/1688).
- **Keep deleted folders deleted in saved computers.** Kandelo now preserves
  those deletions when it compacts saved filesystem changes.
  [Saved-file fix](https://github.com/Automattic/kandelo/commit/bd15db6cc3).
