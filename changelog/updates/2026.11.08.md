## 2026.11.08 — Build with an agent in a browser OS

An agent can edit source, run installed compilers and tests, and inspect
results in the same browser computer you use. WebMCP connects the agent
to Kandelo's commands, files, terminals, and previews. Development commands
run inside the guest OS, using its files and processes.

The computer also runs its own C/C++ and experimental Rust development
tools. Write a program, compile it, run it, and test it in one environment;
the compilers themselves run as Kandelo programs.

This first update collects milestones from March–November 2026.

### Highlights

- **Give an agent a development computer in your browser.** WebMCP lets
  an agent edit files, run installed development tools, and inspect results
  alongside you in the same computer. Requires a browser with WebMCP
  registration support.
  [Explore the agent tools](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/webmcp.md).
- **Compile C and C++ without leaving your browser computer.** Open a Base
  Shell terminal and use `cc` or `c++` to build and run your own programs.
  [Try the C/C++ toolchain](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/sdk-guide.md#compile-inside-the-base-shell).
- **Use Cargo inside Kandelo.** The experimental Rust environment brings
  builds, tests, formatting, Clippy, and documentation into the computer,
  including projects with C/C++ build scripts.
  [Set up the experimental Rust environment](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/rust-target.md#cargo-inside-kandelo).
- **Invite friends into a game.** DOOM, Quake, and Freeciv have multiplayer
  through Kandelo network sessions.
  [Start a network session](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs-site/guide/current-ui.md#network-sessions).

### Breaking Changes & Migration

- **Export important files before updating Kandelo.** Browser computers
  retain files in browser storage, but saved computers from this release
  will not work in the next release. Transactional software upgrades are
  not available yet.
  See the [persistence and compatibility contract](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/persistent-program-compatibility.md).
- **Rebuild programs compiled for ABI 55 or earlier.** The declared supported
  program baseline is ABI 56. Program compatibility and the kernel/host
  interface now have separate version counters; saved-computer upgrades
  remain a separate capability.
  See [compatibility admission](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/persistent-program-compatibility.md#what-a-narrow-program-contract-actually-contains).

### User Interface

- **Keep a computer and come back to your work.** The Library creates and
  reopens computers from Base Shell, Web Stack, and WordPress images.
  Image-backed files persist; scratch files such as `/tmp` reset on reboot.
  The update limitation above still applies.
  [Computer UI milestone](https://github.com/Automattic/kandelo/commit/a1f844271860729a4806898c56bc6950aa20b558).
- **Open another app without rebooting.** Activities launch installed apps
  on your running computer, sharing its files and processes. Switch between
  terminals, web previews, and graphics while their programs keep running;
  an activity stops a conflicting display or managed web activity first.
  [Browser guide](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs-site/guide/current-ui.md).

### Agentic Workflows

- **Build software together in a guest OS sandbox.** Through WebMCP, an
  agent can edit source, invoke the installed compilers and development
  tools, manage command jobs, and inspect results in shared terminals and
  previews. Commands run inside Kandelo's guest OS with the agent account's
  permissions. Browser-origin isolation is a separate boundary: same-origin
  preview scripts share the app's WebMCP trust boundary. Registration requires
  `document.modelContext.registerTool`; capability availability is reported
  by the running environment.
  [WebMCP contract](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/webmcp.md).
- **Teach the agent what your environment can do.** Images and the guest's
  `maker` account can declare additional tools in files. Editing a definition
  refreshes the tool without reloading the computer. Commands run as jobs
  owned by the agent account, with bounded output and cancellation.
  [Image-declared tools](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/webmcp.md#image-declared-tools).
- **Resume development work across agent sessions.** Contributor tools
  retain long-job evidence and checkpoint campaign state across sessions.
  [Campaign guidance](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/agent-guidance/campaigns.md).
- **Integrate reviewed work while preserving local changes.** Contributor
  tools record pinned source and patch identities and journal imported
  validation evidence.
  [Integration workflow](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/agent-integration.md).

### Ports & Packages

- **Bring familiar software into a browser computer.** Use shells and GNU
  tools, Git and editors, Python/Ruby/Perl, or web stacks such as
  nginx/PHP/MariaDB/WordPress. Graphical software includes DOOM, Quake,
  Freeciv, and LÖVE applications.
  Availability and package-specific limits are documented in the
  [package catalog](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/packages/README.md).
- **Build and run C and C++ in the Base Shell.** The `cc` and `c++` commands
  fetch their compiler tools on first use. Source code, compiler processes,
  and the resulting programs all live in the Kandelo computer.
  [SDK guide](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/sdk-guide.md),
  [C/C++ example](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/README.md#build-c-and-c-inside-kandelo).
- **Build Rust projects, including code that calls C and C++.** The
  experimental guest toolchain includes rustc, Cargo, a matching standard
  library, rustfmt, Clippy, and rustdoc. Cargo can compile native dependencies
  through `build.rs` and run unit, integration, and documentation tests.
  Start with the documented development image or optional SDK bundle and
  its offline, single-job build workflow. Procedural-macro
  crates are currently unsupported; arbitrary third-party crates and HTTPS
  registry access are not established by that coverage.
  [Rust inside Kandelo](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/rust-target.md#cargo-inside-kandelo).

### Correctness

- **Make shells and subprocesses agree about what is happening.** Work on
  process waits, signal interruption, file locks, and blocking I/O moves
  state and wakeup decisions into the shared kernel. These changes apply
  to both Node.js and browser hosts; remaining partial interfaces stay
  documented.
  [POSIX status](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/posix-status.md).
- **Address memory retained when switching computers.** Filesystem images
  are composed in disposable workers, and teardown has explicit ownership
  rules for shared memory. Persistent device realms stay separate from
  guest process memory.
  [Host runtime contract](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/agent-guidance/host-runtime.md).

### POSIX Completeness

- **Run programs that start other programs and work together.** The platform
  covers multi-process execution, pipes, terminals, signals, sockets,
  threads, and dynamic linking. POSIX conformance remains
  the goal; the status tables distinguish full, partial, unsupported, and
  planned behavior.
  [Interface status](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/posix-status.md).
- **Use tmux and software built on libevent.** Expanded epoll support enabled
  those ports. Multicast routing also lets networked programs communicate
  across Kandelo machines.
  [epoll milestone](https://github.com/Automattic/kandelo/commit/d51ac6d2ce),
  [multicast milestone](https://github.com/Automattic/kandelo/commit/32a221cb7c).

### New Capabilities

- **Run the same platform in a browser or Node.js.** Kandelo grew from its
  initial kernel and host into a multi-process environment, with package
  resolution and filesystem image tooling shared across the two hosts.
  [Architecture](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/architecture.md).
- **Try a new port without building every package.** Partial images compose
  a root filesystem with your selected packages. Canonical products remain
  the publication and broad-validation path.
  [Partial image workflow](https://github.com/Automattic/kandelo/commit/f762afc103).
- **Run desktop applications in a browser computer.** Graphics work brings
  a Wayland desktop, the Cage/Sway foundation, and a guest graphics driver.
  Cage startup on WebKit remains a known defect, and broader graphics
  conformance is unfinished.
  [Compositor foundation](https://github.com/Automattic/kandelo/pull/1594),
  [graphics compatibility](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/graphics/compatibility-v1.md).
