## 2026.11.08 — Build, share and play in a browser computer

Kandelo puts development tools, web apps and games in a computer that runs
inside your browser. This first update picks out experiences added between
March and November 2026.

### Highlights

#### Build software

- **Compile and run C and C++ in your browser.** Open the Base Shell,
  write a program, then build it with `cc` or `c++`. The compiler and your
  finished program both run inside Kandelo. Compiler tools download on
  first use.
  [Try a C or C++ program](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/README.md#build-c-and-c-inside-kandelo).
- **Build and test Rust projects inside Kandelo.** Use Cargo to build your
  project and run its tests. Format code with rustfmt, check it with Clippy,
  and generate documentation with rustdoc. Projects can also build C and
  C++ dependencies through Cargo build scripts.
  This is experimental: install the development image or optional SDK bundle,
  use the offline workflow with one build job, and choose projects without
  procedural-macro dependencies. Downloading crates over HTTPS is not yet
  established as a supported workflow.
  [Set up Rust](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/rust-target.md#cargo-inside-kandelo).
- **Work with an AI agent in the same browser computer.** WebMCP connects
  an agent to your Kandelo files, terminal commands and app previews. The
  agent can edit code, run installed compilers and tests, and inspect the
  results where you can see them. Its commands run inside Kandelo with the
  agent account's permissions. Requires a browser with WebMCP support;
  see the guide for the trust limits of app previews.
  [Explore WebMCP](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/webmcp.md).

#### Run and share web apps

- **Run WordPress inside a browser tab.** Start a WordPress computer and
  work with a site whose web server, PHP and database all run in Kandelo.
  Choose SQLite or MariaDB for its database.
  [Open a WordPress computer](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs-site/guide/current-ui.md#computers-and-activities).
- **Invite someone to use your running website.** Share a network-session
  invitation for WordPress or a supported web app. The other person opens
  your live site in their preview; you both use the same server and data.
  The hosting computer must stay connected, and the browsers need a working
  peer connection.
  [Share a web app](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/package-sessions.md).

#### Play games

- **Play DOS games with DOSBox Pure.** Start with Commander Keen 1
  shareware or another catalog game, or drop in your own DOS game ZIP.
  Kandelo runs DOSBox Pure's core with graphics, sound, and keyboard and
  mouse controls.
  [Choose a DOS game](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/packages/registry/dosbox-pure/README.md).
- **Play classic adventures with ScummVM.** Download freeware games such
  as *Beneath a Steel Sky* and *Flight of the Amazon Queen* from the game
  activity, or load your own supported game data. The activity marks games
  whose engines are unavailable in this build.
  [Browse adventure games](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/packages/registry/shell/scummvm-freeware-games.json).
- **Bring your console games into Kandelo.** Retro activities run NES,
  SNES, Mega Drive/Genesis, Master System and Game Gear games with sound
  and keyboard controls. Try the included test ROMs or supply your own
  compatible game ROMs. The emulators are FCEUmm, Snes9x and Genesis Plus GX.
  [See the console emulators](https://github.com/Automattic/kandelo/pull/1637).
- **Play DOOM with friends.** Start a cooperative or deathmatch session,
  invite players, and gather in the waiting room before the host starts
  the game. The port includes graphics, sound and music.
  [Set up DOOM multiplayer](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/packages/registry/fbdoom/sessions.json).
- **Host a Quake multiplayer game.** Run Quake through the TyrQuake port
  and connect players' Kandelo computers through a network session. Use
  Quake's multiplayer menus and choose matching game data in the activity.
  [Host or join Quake](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/packages/registry/tyrquake/sessions.json).
- **Build a civilization together in Freeciv.** Play locally or host a
  multiplayer strategy game. Players join Freeciv's lobby to choose their
  nations, map and settings; the game server runs inside Kandelo too.
  [Play Freeciv](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/freeciv.md#multiplayer).

Multiplayer sessions need a working peer connection. Use the game setup to
choose compatible game data for everyone joining.

#### Make the computer your own

- **Move between your terminal and apps without restarting.** Activities
  open apps on the computer you are already using, with access to its files.
  Move between terminals, web previews and graphics while other programs
  keep running. Starting an activity stops a conflicting display or managed
  web activity first.
  [Use activities](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs-site/guide/current-ui.md).
- **Save your work and return to it.** Create a computer in the Library,
  then reopen it with its saved files. Temporary files in `/tmp` reset on
  reboot. Saved computers currently have upgrade limits; see the notice below.
  [Use the Library](https://github.com/Automattic/kandelo/commit/a1f844271860729a4806898c56bc6950aa20b558).
- **Share a starting point for someone else's project.** A setup link
  can include startup settings and a shell script that runs when opened.
  The recipient can inspect, edit and rerun that script in the terminal.
  The link carries setup instructions; it does not copy your saved files.
  [Create a setup link](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs-site/guide/current-ui.md#script-carrying-share-links).

### Breaking Changes & Migration

- **Export important files before updating Kandelo.** Saved computers from
  this release will not work in the next release. Automatic software
  upgrades for saved computers are not available yet.
  [Persistence and upgrade limits](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/persistent-program-compatibility.md).
- **Rebuild older Kandelo programs.** Programs built for ABI 55 or earlier
  need rebuilding for ABI 56. The ABI number identifies the interface between
  a program and Kandelo; kernel/host compatibility has its own version number.
  [Program compatibility](https://github.com/Automattic/kandelo/blob/df8cf7461f23a6d11d4250aadd3c4ddd4789e81e/docs/persistent-program-compatibility.md#what-a-narrow-program-contract-actually-contains).
