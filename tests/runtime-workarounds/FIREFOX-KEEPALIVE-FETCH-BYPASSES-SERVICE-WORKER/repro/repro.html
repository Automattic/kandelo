A document controlled by a service worker fetches the same URL twice: once normally and once with keepalive: true. The Fetch and Service Workers standards send both to the controlling service worker (keepalive does not change a request's service-workers mode). The page reports "reproduced" when the keepalive request reaches the network instead. It also records, without judging them, whether a keepalive Request object and navigator.sendBeacon() reach the worker.
