## Actual owning paths

Missing/nonfunction hooks and primitive results produce no serialization result.
They are not messages containing undefined. Descriptor conversion runs in C++;
catchable deferred errors retain original exception/stack in context-local roots
and a consume-once opaque source-context box. Native cross-thread packets contain
no sender JavaScript roots. Actual caller owns dispatch, drop, retirement and
sender/receiver error precedence. Fatal/OOM paths abort rather than manufacture
prepared data or recoverability.

Worker argv, filename, doEval, workerData and environmentData share one LOAD graph
and transfer registry in target-relative field order. Native environment/CLI
metadata is separate and excludes child entry/source/argv. Decoding happens after
real builtin/host deserializer initialization. The actual consumed initializer
applies array-like argv and real captured loader entry before ready/user code.
The native packet gate owns two independent once-only read slots, keeps absence
pending and serves interrupt/Stop without treating a wait checkpoint as success.
Packet retirement leaves the gate lock before releasing real graph owners.

Reentrant ArrayBuffer detachment uses an actual empty fixed backing store in the
existing outer transfer slot; the original allocation remains with its inner
transfer. Ordinary detached admission and non-Node clone behavior are unchanged.
