# Man page support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users run `man ls`, `man lsof`, and (later) `man <anything>` in the Kandelo shell demos and get the real, readably-formatted manual page for the exact wasm artifact they are running.

**Architecture:** Ship the `man` viewer (mandoc) and per-package `<pkg>-docs` manual sets as `/usr/`-mounted **lazy-archives**, exactly like the python/ruby/node/perl interpreter bundles. Manual content is faithful to the real artifact: authored in-repo for our own tools (`lsof`), and for help2man-style GNU packages (`coreutils`) generated at docs-build time by scraping `--help`/`--version` from the real wasm binaries running **inside a Kandelo instance**. Archives register at VFS image-build time (stubs baked into the `.vfs`); bytes stream on first read.

**Tech Stack:** mandoc (BSD C, renders `-Tutf8`); GNU `help2man` (host, in the Nix dev-shell); Kandelo package resolver + SDK (`wasm32posix-cc`); `NodeKernelHost` (offline docs-generation harness + functional validation); TypeScript VFS image builders; `create-deterministic-zip.sh`.

**Spec:** `docs/superpowers/specs/2026-08-27-man-page-support-design.md` (read it alongside this plan; the plan argues from it).

## Global Constraints

Every task's requirements implicitly include this section. Values are copied verbatim from the spec and the repo contracts.

- **Faithfulness (platform-values contract):** manual text must describe the real wasm artifact. Real mandoc (no custom formatter); `coreutils` pages generated from the real binary run inside Kandelo; `lsof.8` authored because Kandelo *is* the upstream for the in-tree `lsof` (`examples/lsof.c`).
- **Lazy-archive mount contract:** all new archives use `mountPrefix: "/usr/"`; each archive's `requiredMember` must be exactly one regular, non-directory, **non-symlink** file it carries.
- **Deterministic zips only:** produce every `.zip` via `images/vfs/scripts/create-deterministic-zip.sh <staging-dir> <output.zip>` (output must live outside the staging tree).
- **Package identity:** each new package's directory name must equal its `name`; `kernel_abi = 7` (matching sibling packages); `-browser-bundle`/`-docs` archive packages set `fork_instrumentation = "disabled"` on their `[[outputs]]` (a zip is not an instrumentable module); the built `mandoc.wasm` uses `fork_instrumentation = "auto"`.
- **Publish interface:** `install_local_binary <package> <source> [<declared-output-artifact>]`; the third arg must equal `[[outputs]].wasm`. Sealed/resolver builds set `WASM_POSIX_INSTALL_LOCAL_MIRROR=0` (requires `WASM_POSIX_DEP_OUT_DIR`) and an explicit `WASM_POSIX_INSTALL_FORK_INSTRUMENTATION`.
- **Resolver env vars a build script may read:** `WASM_POSIX_DEP_OUT_DIR`, `WASM_POSIX_DEP_WORK_DIR`, `WASM_POSIX_DEP_TARGET_ARCH` (`wasm32`), `WASM_POSIX_DEP_SOURCE_DIR`/`_SOURCE_URL`/`_SOURCE_SHA256` (archive provider), and one `WASM_POSIX_DEP_<NAME>_DIR` per direct program/library dependency (name upper-cased, `-`→`_`). Install only into `WASM_POSIX_DEP_OUT_DIR`.
- **Do not commit `packages/registry/program-packages.json`** — it is gitignored and regenerated by `build-deps program-index`; committing a locally-regenerated copy causes cacheKey drift.
- **Do not commit a recipe you cannot build here** (CLAUDE.md). A package with no binary falls back to a source build that must actually succeed; commit `mandoc`/`coreutils-docs`/`lsof-docs` recipes only after they build in this worktree.
- **Build/verify only through the dev-shell:** `bash scripts/dev-shell.sh <cmd>` (nix `--ignore-environment`). `sdk/activate.sh` uses `${BASH_SOURCE[0]}`, so run build commands via `bash -c`.
- **Validation contract:** back each claim with the evidence for that exact claim, and report what ran on which host. A passing Node/Vitest path does not prove browser behavior; verify user-visible browser output with `?demo=shell`.
- **PR/commit prefix:** `Area: Purpose`; these are `Packages:` changes. `## Why` before `## What changed` in the PR body; wrap prose at 72 columns.

- [ ] **Step 3: Write `build-mandoc.sh`.** mandoc has no autotools; its `./configure` writes `Makefile.local` and reads `configure.local` for overrides. Cross-compile with the SDK, disable the interactive terminal/pager path where it fights wasm, and install into a DESTDIR stage. ```bash
#!/usr/bin/env bash
# Build mandoc (the man viewer/formatter) for wasm32. Produces mandoc.wasm;
# the `man` front-end is installed as a bin/man symlink to mandoc.
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
REPO_ROOT="$(cd "$SCRIPT_DIR/../../.." && pwd)"
source "$REPO_ROOT/scripts/package-build-roots.sh"
kandelo_package_prepare_build_roots "$SCRIPT_DIR" wasm32
kandelo_package_stage_verified_source   # fetch+verify+unpack the archive-provider tarball
SRC="$KANDELO_PACKAGE_SOURCE_ROOT"
WORK_DIR="$KANDELO_PACKAGE_WORK_DIR"
STAGE="$WORK_DIR/stage"
rm -rf "$STAGE"; mkdir -p "$STAGE"

CC="wasm32posix-cc"
command -v "$CC" >/dev/null || { echo "build-mandoc: $CC not on PATH (use dev-shell)" >&2; exit 2; }

cd "$SRC"
# mandoc reads configure.local for cross overrides. Point the compiler at the
# SDK, install under /usr, and skip build-host feature probes that assume a
# native toolchain. UTF-8 output is the default renderer we rely on.
cat > configure.local <<EOF
CC="$CC"
CFLAGS="-O2"
PREFIX="/usr"
BINDIR="/usr/bin"
MANDIR="/usr/share/man"
HOMEBREWDIR=
LDADD=
EOF

./configure
make -j"$(getconf _NPROCESSORS_ONLN 2>/dev/null || echo 4)"
make DESTDIR="$STAGE" install

# Ensure the man front-end exists as a bin/man symlink to mandoc. mandoc's
# installer usually creates it; create it if the install layout differs.
if [ ! -e "$STAGE/usr/bin/man" ]; then
    ln -s mandoc "$STAGE/usr/bin/man"
fi
[ -f "$STAGE/usr/bin/mandoc" ] || { echo "build-mandoc: mandoc binary missing after install" >&2; exit 2; }

# The resolver expects the primary output as <out>/mandoc.wasm. The SDK emits a
# wasm module; stage it under the declared name.
cp "$STAGE/usr/bin/mandoc" "$WORK_DIR/mandoc.wasm"

source "$REPO_ROOT/scripts/install-local-binary.sh"
if [ -n "${WASM_POSIX_DEP_OUT_DIR:-}" ]; then
    WASM_POSIX_INSTALL_LOCAL_MIRROR=0 WASM_POSIX_INSTALL_FORK_INSTRUMENTATION=auto \
        install_local_binary mandoc "$WORK_DIR/mandoc.wasm"
    # Stage the full install tree for the browser-bundle reshaper (Task 2).
    cp -R "$STAGE/usr" "$WASM_POSIX_DEP_OUT_DIR/usr"
else
    WASM_POSIX_INSTALL_FORK_INSTRUMENTATION=auto \
        install_local_binary mandoc "$WORK_DIR/mandoc.wasm"
fi
```

Implementation risk to resolve while writing this step: (a) mandoc's `./configure` runs build-host compile probes — if any probe hard-fails under the SDK, add the matching `HAVE_*` override to `configure.local` (mandoc documents every knob in its `configure` script's comments). (b) mandoc's `man` mode may `fork()` a pager; that is fine (Kandelo supports instrumented fork, and `fork_instrumentation = "auto"` is set) but paging is disabled at runtime via `MANPAGER` in Task 7 so rendering goes straight to stdout.

#!/usr/bin/env bash
set -euo pipefail
SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
MANDOC_DIR="$1"; OUTPUT_FILE="$2"
[ -f "$MANDOC_DIR/mandoc.wasm" ] || { echo "mandoc.wasm not found under $MANDOC_DIR" >&2; exit 1; }

STAGING="$(mktemp -d "${WASM_POSIX_DEP_WORK_DIR:-/tmp}/man-zip.XXXXXX")"

bash "$SCRIPT_DIR/create-deterministic-zip.sh" "$STAGING" "$OUTPUT_FILE"

  "arch","base32","base64","basename","basenc","cat","cksum","comm","cp",
  "csplit","cut","date","dd","df","dir","dircolors","dirname","du","echo",
  "env","expand","expr","factor","false","fmt","fold","groups","head",
  "hostid","id","join","link","ln","logname","ls","md5sum","mkdir","mkfifo",
  "mknod","mktemp","mv","nice","nl","nohup","nproc","numfmt","od","paste",
  "pathchk","pr","printenv","printf","ptx","pwd","readlink","realpath","rm",
  "rmdir","seq","sha1sum","sha224sum","sha256sum","sha384sum","sha512sum",
  "shred","shuf","sleep","sort","split","stat","stty","sum","sync","tac",
  "tail","tee","test","timeout","touch","tr","true","truncate","tsort","tty",
  "uname","unexpand","uniq","unlink","vdir","wc","whoami","yes","b2sum",
  "basename","chcon","chgrp","chmod","chown","chroot","cksum","install",
  "kill","runcon","tail",
];

async function capture(bin: string, tool: string, flag: string): Promise<string> {
  const { stdout } = await runCentralizedProgram({
    programPath: bin,
    argv: [tool, flag],
    env: ["PATH=/usr/bin:/bin", "POSIXLY_CORRECT=1"],
  });
  return stdout;
}

async function main() {
  const [bin, outDir] = process.argv.slice(2);
  mkdirSync(outDir, { recursive: true });
  const uniq = Array.from(new Set(TOOLS)).sort();
  for (const tool of uniq) {
    const help = await capture(bin, tool, "--help");
    const version = await capture(bin, tool, "--version");
    if (!help.trim()) { console.error(`skip ${tool}: empty --help`); continue; }
    writeFileSync(join(outDir, `${tool}.help`), help);
    writeFileSync(join(outDir, `${tool}.version`), version);
  }
}
main().catch((e) => { console.error(e); process.exit(1); });
```
Note: dedupe/sort the list (the array above intentionally lists the canonical set; a couple of names repeat and are collapsed by the `Set`). If a tool prints empty `--help` inside Kandelo, log and skip it — a missing page is honest; do not fabricate one.
